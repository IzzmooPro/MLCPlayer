MLC Player — third-party notice for the bundled mpv / FFmpeg component
================================================================

MLC Player uses the library build of mpv (libmpv) for playback and
redistributes `_internal\bin\mpv-2.dll` with the package. That binary
includes FFmpeg. The details below are copied from
`bin/RUNTIME_MANIFEST.txt`; if the two ever disagree,
`tests/test_third_party_notice_regressions.py` fails.


1. COMPONENT
----------------------------------------------------------------

File     : mpv-2.dll  (libmpv)
Version  : mpv v0.41.0-930-g49418246f (FFmpeg N-126239-g88ae625e6)
Licence  : GPLv3
SHA-256  : DE80329F5C019BA2EE48184B5DC1E1D0C2EE9EEBA3F1FB7959F20B4B0F684F4E


2. LICENCE
----------------------------------------------------------------

This build is configured with `--enable-gpl --enable-version3` and is
therefore licensed under the GPLv3. The build carries no nonfree
components (no fdk-aac, libnpp or cuda-nvcc), which keeps it compatible
with MLC Player's own GPLv3 licence.

The full GPLv3 text ships with MLC Player as the `LICENSE` file in the
installation directory. mpv and FFmpeg fall under that same text, so no
second copy is carried here.

4. NO MODIFICATIONS
----------------------------------------------------------------

MLC Player does not modify the mpv or FFmpeg source. The bundled
`mpv-2.dll` was built from the captured upstream revisions by the project's
source-captured build workflow.
